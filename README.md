# 仕様

## Carousel

### スライド移動

- Previous押下で前のスライドに移動
    - 一番最初のスライドのときは最後のスライドに移動
- Next押下で次のスライドに移動
    - 一番最後のスライドのときは最初のスライドに移動
- 対応するドットを押したときに該当するスライドに移動
- ドット/Previous/Next押下時に自動再生のタイマーをリセットする
- アニメーション中は操作を受け付けない

### 自動再生

- 間隔：5秒
- 初期ロード時はスライドを自動で再生
- 再生中の場合
    - ボタン押下でスライドを停止
    - 停止ボタンを非表示にし、再生ボタンを表示
- 停止中の場合
    - ボタン押下でスライドを再生
    - 再生ボタンを非表示にし、停止ボタンを表示

### A11y

- キーボードのみですべての操作ができる（矢印キーでのスライド移動は任意）
- スライドの表示/非表示に応じてinert属性をつけ外し
- アクティブなドットにaria-current="true"を付与

### スワイプ操作（任意）

- モバイル端末においてスワイプでスライド移動ができる

### JS無効時

- スライドをすべて表示する
- インジケーターは非表示にする
