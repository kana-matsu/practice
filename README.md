# 仕様

## Carousel

### スライド移動

- [x] Previous押下で前のスライドに移動
    - [x] 一番最初のスライドのときは最後のスライドに移動
- [x] Next押下で次のスライドに移動
    - [x] 一番最後のスライドのときは最初のスライドに移動
- [x] 対応するドットを押したときに該当するスライドに移動
- [x] ドット/Previous/Next押下時に自動再生のタイマーをリセットする
- [x] アニメーション中はスライド移動処理をストップ

### 自動再生

- [x] 間隔：5秒
- [x] 初期ロード時はスライドを自動で再生
- [x] 再生中の場合
    - [x] ボタン押下でスライドを停止
    - [x] 停止ボタンを非表示にし、再生ボタンを表示
- [x] 停止中の場合
    - [x] ボタン押下でスライドを再生
    - [x] 再生ボタンを非表示にし、停止ボタンを表示

### A11y

- [ ] キーボードのみですべての操作ができる
    - [ ] 矢印キーでのスライド移動（任意）
- [x] スライドの表示/非表示に応じてinert属性をつけ外し
- [x] アクティブなドットにaria-current="true"を付与
- [ ] その他必要なrole, aria属性を付与

### スワイプ操作（任意）

- [x] モバイル端末においてスワイプでスライド移動ができる
    - [x] 画面タッチ時はスライド移動処理をストップ
    - [x] タッチ面に沿って移動した方向にスライド移動
    - [x] スワイプ中にスライドを指に追従させる
    - [x] 縦方向の移動量 < 横方向の移動量の場合のみスライド移動、そうでない場合は元のスライド位置に戻す
    - [x] タッチ距離が短すぎる場合はスライド移動しない
    - [x] スワイプ時のタイマーリセット

### ループ

- [x] スライドをループさせる（×rewind）
    - [ ] 最初/最後のスライドから前/次のスライドに移動するときに自然なアニメーションになるように調整

### JS無効時

- [ ] スライドをすべて表示する
- [ ] インジケーターは非表示にする

### 拡張

- [ ] スライド間隔を調整できるようにする
- [ ] 表示枚数を選択できるようにする
- [ ] 自動再生の有無を選択できるようにする
